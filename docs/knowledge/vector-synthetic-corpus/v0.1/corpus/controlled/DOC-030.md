# DOC-030 — Spring Boot Kubernetes probe paths

Spring Boot can expose Kubernetes-oriented health groups when `management.endpoint.health.probes.enabled=true`. The liveness and readiness groups should be mapped to HTTP paths and checked by the platform. Application-specific readiness contributors may report that a required search dependency is not ready.

Enabling probe paths is not equivalent to defining a startup budget. Pair readiness and liveness endpoints with an appropriate Kubernetes startup probe when initialization can take longer than the liveness threshold.
