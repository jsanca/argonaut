# DOC-023 — Query normalization and typos

Query normalization can fold case, trim whitespace, and apply a configured analyzer before lexical retrieval. Spell correction and fuzzy matching can recover minor typos such as `readines porbe`, but they can also broaden a query to unrelated terms.

Evaluate noisy input separately from exact identifier lookup. An analyzer that corrects human prose must not silently rewrite an exact configuration key or an opaque API name.
