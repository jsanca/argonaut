# DOC-004 — Retrieval observability record

Each retrieval should emit an observation with the query identifier, corpus version, retrieval strategy, index configuration, requested K, returned document identifiers, rank, score, elapsed time, and failure status. The observation records retrieval, not generated prose.

For comparative runs, retain the complete ranking up to the configured cutoff. Aggregate recall, reciprocal rank, and discounted cumulative gain can then be calculated from fixed relevance judgments without asking an LLM to judge an answer.
