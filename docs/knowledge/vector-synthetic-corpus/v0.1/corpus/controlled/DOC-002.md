# DOC-002 — Argonaut HNSW query setting

Argonaut Vector exposes `argonaut.vector.hnsw.ef-search` as the requested HNSW query-time candidate breadth. Set it per experiment so ranked retrieval runs can compare recall and latency under the same corpus and query set.

This property is not an embedding-model setting and does not select an index type. A larger `ef-search` usually asks the HNSW implementation to inspect more candidates before returning the requested top K. Record its configured value with experiment results.
