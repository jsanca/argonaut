# DOC-029 — Argonaut embedding model setting

`argonaut.vector.embedding.model` identifies the embedding model label recorded with an Argonaut Vector run. It supports experiment provenance; changing the label alone does not download a model or alter an already-created collection.

The embedding model determines vector representation and dimension. Before switching models, validate compatibility with the target index and record the model label alongside corpus version, chunking policy, index configuration, and retrieval metrics.
