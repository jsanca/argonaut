# DOC-003 — Selecting a vector index

An exact FLAT index compares a query vector with every stored vector. It offers a useful correctness baseline for a small controlled corpus. HNSW builds a navigable graph and trades some exactness for lower query latency at scale.

Index selection should be reported separately from embedding model, chunking policy, and result limit. A ranked-list difference can otherwise be wrongly attributed to the index. HNSW parameters such as graph construction degree and query search breadth affect the recall/latency trade-off.
