# DOC-026 — Cache invalidation is not index rebuilding

An application response cache stores prior request outcomes for a bounded period. A vector index stores searchable representations of source content. Invalidating a response cache does not rebuild embeddings, and rebuilding an index does not necessarily clear a response cache.

Operational runbooks should identify which layer is stale: source documents, chunks, embeddings, vector index, metadata filter, or response cache. Similar use of the word "cache" is a strong lexical distractor in retrieval tests.
