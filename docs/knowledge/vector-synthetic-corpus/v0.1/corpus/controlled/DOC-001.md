# DOC-001 — HNSW graph navigation

Hierarchical Navigable Small World (HNSW) is an approximate nearest-neighbor index. It stores vectors in a multi-layer proximity graph. Search begins at sparse upper layers to move toward the query region, then descends to denser layers for a local search. The result is a fast approximation rather than an exhaustive comparison against every vector.

Two common tuning controls are graph degree during construction and the breadth searched at query time. More breadth can improve recall but costs latency. HNSW is useful when a collection is large enough that exact scan is too slow and a small recall trade-off is acceptable.
