# DOC-012 — Spring Boot external configuration

Spring Boot resolves configuration from packaged defaults, external files, environment variables, command-line arguments, and other configured property sources. Deployment-specific values should be supplied outside the application artifact.

Use a typed `@ConfigurationProperties` class for a coherent settings group. Environment variables use uppercase underscore names such as `ARGONAUT_VECTOR_PROVIDER`; Spring's relaxed binding maps them to conventional property names. Do not commit provider credentials in application YAML.
