# DOC-020 — HNSW recall tuning note

For an HNSW experiment, increase query search breadth only after recording the baseline recall at a fixed result limit. The query-time setting explores more graph candidates; it is a recall/latency control, not a promise of exact nearest neighbors.

This note concerns tuning an approximate-neighbor search. It does not define the HNSW graph algorithm, and it does not name an Argonaut configuration property. Keep implementation-specific property keys in deployment documentation so lexical lookup can find them exactly.
