# DOC-027 — REST pagination cursors

Cursor pagination returns an opaque continuation token derived from the last stable sort position. It avoids the shifting-window problem of offset pagination when records are inserted between requests. A cursor should be treated as opaque by clients.

Use a deterministic sort key and document whether deleted or newly created records can appear during traversal. Pagination concerns collection traversal; it is unrelated to HNSW graph navigation despite both using the language of "next" results.
