# DOC-009 — Hybrid retrieval and rank fusion

Hybrid retrieval combines lexical and dense candidate lists. A simple approach retrieves independently from BM25 and a vector index, then applies reciprocal rank fusion (RRF). RRF rewards documents that appear near the top of either list without requiring their raw scores to be calibrated to the same scale.

Hybrid retrieval is not automatically better. It adds candidate and fusion choices that must be fixed before comparing runs. Its value is often visible when one result contains an exact identifier and another is a semantic paraphrase.
