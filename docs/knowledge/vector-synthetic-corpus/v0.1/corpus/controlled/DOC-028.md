# DOC-028 — Retrieval architecture boundary

Keep application documents, embeddings, vector storage, and search results as distinct concepts. An embedding adapter converts text to a vector; a store persists vectors; a search adapter returns ranked document references. The common experiment contract should not expose a database vendor's request or response type.

This separation allows the same corpus and relevance judgments to run against an in-memory cosine baseline, an embedded index, or a remote vector database. Backend-specific tuning belongs in run configuration and observations, not in the corpus.
