# DOC-024 — Rollout incident: Ready before retrieval dependency

During a retrieval-service rollout, a Pod can report ready before a required local index restore has completed if readiness only checks the HTTP server. Requests may then receive `503` while the index is unavailable. The readiness contract must include the dependency that makes the advertised operation usable.

Expose a clear reason for the not-ready state and keep the initialization budget bounded. A startup probe protects a slow process from premature liveness restarts; it does not by itself guarantee that readiness verifies every required dependency.
