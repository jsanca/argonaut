# DOC-007 — Cosine similarity and normalized embeddings

Cosine similarity compares the angle between two embedding vectors. If document and query embeddings are L2-normalized, their dot product equals cosine similarity. Normalization lets an in-memory implementation compute a simple dot product while preserving cosine ranking.

Normalization does not repair a poor embedding model or a bad chunk boundary. It only makes the selected similarity metric consistent with the vector representation.
