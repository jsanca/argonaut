# DOC-021 — Qdrant HNSW collection configuration

Qdrant can use an HNSW index for vector search within a collection. Its collection-level HNSW configuration controls graph construction behavior, while search parameters control the candidate breadth used for a request. These controls are specific to the Qdrant backend API.

Do not copy a Qdrant HNSW setting into a different vector engine without checking its semantics. Record the collection distance metric, vector size, HNSW settings, and Qdrant version with a benchmark run.
