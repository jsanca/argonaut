# DOC-008 — BM25 lexical retrieval

BM25 is a lexical ranking function based on query term frequency, document term frequency, and document-length normalization. It is strong when a query contains a rare identifier, an exact configuration key, or terminology copied from a log.

BM25 does not inherently know that two different phrases have similar meanings. Stemming, analyzers, and synonyms can help, but they are deliberate index choices that must be recorded for a fair comparison.
