# DOC-018 — Metrics for retrieval services

Use counters for request outcomes, histograms for retrieval latency, and gauges for bounded current values such as loaded document count. A latency histogram should distinguish successful retrieval, empty result, timeout, and backend error when those outcomes have different operational meaning.

Metric names need stable units and low-cardinality labels. `retrieval_strategy` and `status` are useful labels; raw query text and document identifiers create unbounded cardinality and should be captured in traces or controlled experiment records instead.
