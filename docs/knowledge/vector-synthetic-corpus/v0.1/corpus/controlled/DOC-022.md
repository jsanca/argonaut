# DOC-022 — Embedding dimension mismatch

An embedding dimension mismatch is a schema error: the encoder produced a vector length different from the index or collection expects. It is not solved by cosine normalization, HNSW tuning, or changing the query limit.

Validate the embedding dimension during startup and before a batch write. If a model change moves from 384 to 768 dimensions, create a compatible collection or rebuild the index; do not mix old and new vectors in the same field.
