# DOC-014 — Qdrant collections and vector size

A Qdrant collection declares the vector configuration used by its points, including vector size and distance metric. Every point written to that vector field must have the configured number of dimensions. A 384-dimensional embedding cannot be inserted into a collection configured for 768 dimensions.

Create or validate the collection before bulk ingestion. Store a stable application document identifier in payload so returned point identifiers can be mapped back to corpus documents.
