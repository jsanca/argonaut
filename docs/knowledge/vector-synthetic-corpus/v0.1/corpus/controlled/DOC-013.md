# DOC-013 — Kubernetes Service routing

A Kubernetes Service gives clients a stable DNS name and selects backend Pods by labels. The Service `selector` must match the labels applied by the Deployment Pod template. `targetPort` identifies the port exposed by the selected container.

A ready endpoint is normally required before traffic is sent through a Service. When requests fail after a rollout, inspect Service selectors, endpoint slices, readiness, and target ports before changing application code.
